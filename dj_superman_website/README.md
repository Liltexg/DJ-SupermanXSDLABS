# DJ SupermanSA3 - Official Website

This repository contains the official website for DJ SupermanSA3, a South African DJ, MC, and entertainer. The website is a static HTML, CSS, and JavaScript site designed to showcase DJ SupermanSA3's services, music, events, and contact information.

## Features

*   **Homepage:** Introduces DJ SupermanSA3 with CTAs for booking and latest mixes, and sections for About, Latest Videos, Upcoming Events, and latest TikToks.
*   **About Page:** Detailed biography of DJ SupermanSA3, his experience, and musical styles.
*   **Music & Videos Page:** Sections for latest mixes, live performances, vlogs, and links to streaming platforms.
*   **Events Page:** Lists upcoming and past events with details.
*   **Contact Page:** A form for bookings/inquiries and links to social media profiles.
*   **Responsive Design:** The website is designed to be viewable on various devices, including desktops, tablets, and mobile phones, featuring a hamburger menu for mobile navigation.
*   **Dark Theme:** Modern dark theme with neon blue accents.

## How to View Locally

1.  Clone this repository or download the files.
2.  Navigate to the `dj_superman_website` directory.
3.  Open the `index.html` file in your preferred web browser (e.g., Chrome, Firefox, Safari, Edge).

## Deployment

This is a static HTML, CSS, and JavaScript website. It can be deployed using various hosting services:

1.  **Netlify:**
    *   Drag and drop the `dj_superman_website` folder directly to Netlify's deploy interface.
    *   Alternatively, connect a Git repository (GitHub, GitLab, Bitbucket) for continuous deployment.
    *   Netlify offers a generous free tier and handles HTTPS automatically.

2.  **Vercel:**
    *   Similar to Netlify, Vercel allows easy deployment by connecting a Git repository or uploading the folder.
    *   Vercel also has a good free tier and automatic HTTPS.

3.  **GitHub Pages:**
    *   If the project is hosted on GitHub, you can serve the website directly from a repository.
    *   Go to Repository Settings -> Pages. Choose the branch and folder to deploy (e.g., `main` branch, `/` (root) or `/docs` folder if you move the contents of `dj_superman_website` there).
    *   Free hosting for public repositories.

4.  **Other Cloud Providers:**
    *   Services like AWS S3, Google Cloud Storage, or Azure Blob Storage can host static websites. These are more complex to set up initially but offer robust and scalable solutions.

5.  **Traditional Web Hosting:**
    *   Most shared hosting providers allow you to upload static files via FTP or a file manager in their control panel.

**To Deploy:**
*   Choose a hosting provider.
*   If using a Git-based provider, commit all files in the `dj_superman_website` directory to a Git repository and connect it to your chosen host.
*   If using a drag-and-drop or FTP method, ensure the entire contents of the `dj_superman_website` folder are uploaded to the root directory of your hosting space (or the appropriate subdirectory like `public_html`).
*   Once deployed, the hosting provider will give you a URL (e.g., `your-site-name.netlify.app` or `your-username.github.io/your-repo-name`).
*   You can then configure a custom domain (e.g., `djsupermansa3.co.za`) through your hosting provider's settings, which usually involves updating DNS records with your domain registrar.
